# MedCare

Azure Cloud Platform & Hybrid Infrastructure

MedCare is a healthcare organization operating across multiple locations in the Netherlands. Its IT environment supports healthcare professionals, administrative staff, connected devices, and internal business services.

This repository contains the design, infrastructure, automation, and operational documentation for MedCare's transition toward a modern hybrid cloud environment built around Microsoft Azure.

The project covers the full environment—from the existing on-premises infrastructure and network connectivity to Azure identity, governance, security, workloads, monitoring, and automation.
