# MedCare

## Azure Cloud Platform & Hybrid Infrastructure

MedCare is a healthcare organization with locations across the Netherlands, including Amsterdam, Rotterdam, The Hague, Utrecht and additional locations.

Thousands of healthcare employees work across these locations and rely on MedCare's IT environment for their daily work. This includes internal applications, company provided mobile devices, connected healthcare devices and communication systems used to deliver important healthcare alarms and notifications.

The current environment is a combination of on-premises infrastructure, local networks and cloud services. Some systems are managed locally at healthcare locations, while other services are centralized and shared across the organization.

This repository contains the design and implementation of MedCare's transition toward a modern hybrid cloud environment built around Microsoft Azure.

The project covers the wider IT environment, including:

* Existing on-premises infrastructure
* Network connectivity between locations
* Microsoft Entra ID and identity
* Azure governance and security
* Cloud and hybrid workloads
* Monitoring and logging
* Infrastructure as Code
* Automation and deployment
* Backup and disaster recovery

The goal is to build an Azure platform that works alongside the existing infrastructure and provides MedCare with a secure, reliable and scalable foundation for future growth.

The environment will be developed step by step, starting with the Azure foundation and gradually expanding into networking, security, workloads, monitoring and automation.

The project is actively being developed.
